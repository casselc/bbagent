# bbagent Vision

`bb4t` provides execution. `bbagent` provides agency.

The long-term product is a native, deeply customizable Clojure agent environment
with persistent computation, durable history, explicit memory, semantic
capabilities, policy, and an interactive Dirge-like experience. Product features
remain application-owned unless they are stable low-level execution primitives.

A0 deliberately proves only one bounded, read-oriented, resumable agent harness.
